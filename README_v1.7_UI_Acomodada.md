# Whisper Transcriptor DPI - v1.7 UI acomodada

Version con la misma base de v1.6, pero con la interfaz acomodada:

- Ruta del archivo en una sola linea, sin romper el panel.
- Opciones ordenadas en grilla compacta.
- Botones de exportacion mas chicos.
- Panel superior mas bajo para dejar mas lugar a la transcripcion.
- Mejor proporcion entre texto completo y segmentos.
- Se mantiene P/R inteligente llamada, limpieza policial, hilos, troceo y cache del modelo.

Uso:
1. Ejecutar `run_app.bat` si ya tenes dependencias instaladas.
2. Si usas EXE, ejecutar `build_windows.bat` para compilar de nuevo.

Configuracion recomendada:
- Modelo: small
- Idioma: Espanol
- Formato: P/R inteligente llamada
- Rendimiento: Rapido
- Hilos: Auto
- Trocear: 15 min
